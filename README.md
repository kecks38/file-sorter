# File Sorter

Небольшой скрипт на Python, который раскладывает файлы из папки по подпапкам в зависимости от расширения.

## Что делает

Скрипт берёт все файлы в корне указанной папки и перемещает каждый в подпапку по типу:

| Расширение | Папка |
|---|---|
| `.abc` | `abc_files` |
| `.bmp` | `bmp_files` |
| `.txt` | `txt_files` |
| `.zip` | `zip_files` |
| любое другое (и файлы без расширения) | `other_files` |

- Подпапки создаются автоматически, если их ещё нет.
- Регистр расширения не важен: `.TXT` и `.txt` попадают в одну папку.
- Вложенные папки скрипт не трогает, только файлы в корне.
- Если в папке назначения уже есть файл с таким именем, скрипт его не перезаписывает, а пропускает и выводит сообщение. Остальные файлы при этом обрабатываются как обычно.

## Как запустить

1. Установите Python 3.
2. В файле `sorter script.py` в переменной `path` укажите путь к нужной папке.
3. Запустите:

```
python sorter script.py
```

**Внимание:** скрипт перемещает файлы. Сначала проверьте его на тестовой папке.

## Что использовано

`pathlib`, `shutil`, словари, обработка исключений (`try/except`).
